# Digital Birthday Surprise Website ??

A premium, highly interactive, mobile-first birthday surprise web experience crafted with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## ?? Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run TypeScript check
npm run typecheck

# Run ESLint
npm run lint

# Build for production
npm run build
```
